Basic Search

Just type a word and Tim searches card names.

lightning— any card with "lightning" in the name
bolt— anything "bolt"-adjacent

Wrap it in "quotes" and Tim searches both the name and oracle text for that exact phrase.

"draw a card"— name or text contains this phrase
"enters the battlefield"— all your ETB triggers

Prefix with ! to match an exact card name — nothing more, nothing less.

!Lightning Bolt— the OG, not Lightning Strike, not Lightning Helix
✨ All searches are case-insensitive. LIGHTNING, lightning, LiGhTnInG — Tim doesn't judge.

Keyword Filters

The good stuff. Use keyword:value to target specific fields. Stack 'em up — Tim ANDs them all together by default.

FilterShort formWhat it searches
name:n:Card name (partial match)
oracle:o:Oracle / rules text (partial match)
type:t:Full type line — supertypes, types and subtypes
keyword:kw:Keyword ability (Flying, Trample, Deathtouch…)
artist:a:Artist name (partial match)
t:goblin t:warrior— Goblin Warriors specifically
o:"whenever a creature dies"— death trigger effects
kw:flying kw:vigilance— has BOTH flying AND vigilance
t:creature -t:human— creatures that aren't Human

Colour & Identity

W U B R G C

c: filters by a card's actual colours. id: (alias: identity:) filters by colour identity — the Commander-relevant version.

c=rg or c:gruulExactly Red and Green — no more, no less

Stats & Numbers

Numeric filters support comparison operators: > < >= <= = !=

FilterAlsoWhat it does
mv:manavalue: cmc:Mana value (converted mana cost)
pow:power:Power
tou:toughness:Toughness
pt:powtou:Power + Toughness combined
mv<=3 c:u t:instant— cheap Blue instants
pow>=8— absolute units
pow>tou— attacks harder than it defends
mv:even t:creature— even-cost creatures (try "odd" too)
pt>=10 c:g— big chunky Green stompers
✨ mv:even and mv:odd are special values. You can also compare stats against each other: pow>tou, tou>pow, and so on.
💎

Rarity

Use r: or rarity:. Supports comparisons (> < >=) because rarity is ordered: Common < Uncommon < Rare < Mythic.

r:mythic c:r— Red mythics
r>=rare t:instant— Rare or Mythic instants
r:common t:artifact— Common artifacts (Pauper enjoyers, this one's for you)

Shorthand works too: c u r m for Common / Uncommon / Rare / Mythic.

Custom Tags

Cards On Tap lets you tag your own cards — and Tim can search those tags directly with tag:.

tag:ramp c:g— your tagged ramp cards that are Green
tag:bulk -r:common— bulk pile stuff that isn't commons
tag:trade is:reprint— trade fodder that's available as reprints
💡 Tag names are case-insensitive. tag:RAMP and tag:ramp find the same cards.
🧩

Logic & Grouping

Multiple filters are ANDed by default. But you've got more tools if you need them:

-filter
Negate — exclude everything matching this
A OR B
Either condition can match (OR must be caps)
(group)
Group conditions together
"phrase"
Exact phrase in name or oracle text
!Card Name
Exact card name — not partial, exact
(t:goblin OR t:elf) r:rare— rare Goblins or Elves
t:creature (c:r OR c:g) mv<=3— cheap Red or Green creatures
-fire c:r t:instant— Red instants that aren't named after fire
(c:izzet OR c:dimir) -t:creature— UR or UB non-creatures
⚠️ OR must be in CAPITALS. Lowercase "or" gets treated as a word to search for. Tim's pretty chill about most things, but this one matters.

What Tim Can't Do

Tim's wise, but TAK.db doesn't have everything. These Scryfall keywords will trigger a warning and be ignored — Tim will still search using whatever else you gave him.

ft: / flavor: usd: / eur: / tix: wm: / watermark: cube: art: / atag: function: / otag: border: / frame: b: / block: lang: in: loy: / loyalty: order: / direction: unique: / prefer:
💡 Tim won't crash on these — he'll show a warning and carry on. Good lad.
